# CalculateAOB

Input the data the program asks for and it spits out a good estimation of the AOB. <br>

Make sure your measurements are accurate. Using decimals is 200% recommended or program might fail or give out an inaccurate AOB. <br>

NOTE: <br>
When inputting length in centiradians, make sure to count each tick as 1. So 3 ticks means 3 centiradians. You might notice that 5 ticks are equal to 10 centiradians on the periscope , so alternatively you may also use those measurements and then divide by 2.
